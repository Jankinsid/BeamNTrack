# BeamNTrack wiki

BeamNTrack is a live ride tracker for BeamNG.drive. It draws the route you drive on the level's map and keeps statistics for every trip.

## Pages

- **[The BeamNG mod](The-BeamNG-Mod)**: what the mod does, how to install it, what it sends and how to fix it when the app can't connect.

## Quick start

1. Copy `beamntrack_mod.zip` into your BeamNG `mods` folder. Leave it zipped.
2. Run `BeamNTrack.exe`.
3. Start BeamNG, load a map and drive.

See the [README](../blob/main/README.md) for the full guide.
